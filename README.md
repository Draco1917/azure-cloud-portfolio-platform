# Azure Cloud Portfolio Platform

## Overview

This project demonstrates the deployment and management of a cloud-hosted portfolio website using Microsoft Azure.

The solution utilizes Azure Storage Static Website Hosting and incorporates monitoring, alerting, notification automation, and cost governance controls.

## Technologies Used

* Microsoft Azure
* Azure Storage Accounts
* Azure Blob Storage
* Azure Static Website Hosting
* Azure Monitor
* Azure Action Groups
* Azure Cost Management
* HTML
* CSS

## Architecture

* Resource Group: rg-portfolio-dev
* Storage Account: austinportfolio001
* Static Website Hosting
* Azure Monitor Alert Rules
* Action Groups
* Email Notifications
* SMS Notifications
* Monthly Budget Controls

## Features

### Website Hosting

* Static website deployment
* Custom 404 error page
* Multi-page portfolio structure

### Monitoring

* High Website Traffic Alert
* Transaction monitoring
* Email notifications
* SMS notifications

### Cost Governance

* Monthly budget limit
* 80% budget alert
* 100% budget alert

## Lessons Learned

* Azure Storage can provide a low-cost hosting solution for static websites.
* Monitoring and alerting are important components of cloud operations.
* Cost governance should be implemented early in a project lifecycle.
* Resource Groups simplify cloud resource management.
